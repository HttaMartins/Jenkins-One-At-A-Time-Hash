🧠 Sobre o Hash Jenkins
O algoritmo Jenkins One At A Time Hash é uma função de hash eficiente e simples, muito utilizada para gerar chaves hash a partir de strings, sendo útil em tabelas de dispersão (hash tables) e outras aplicações.
