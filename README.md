#Compilando

Para compilar o programa é necessário que os arquivos main.c, jenkins.c e jenkins.h estejam na mesma pasta.

Então compilamos da seguinte forma: 
gcc main.c jenkins.c -o programajenkins

e então executamos o programa da seguinte forma:
./programajenkins

Então o programa estará funcionando nomralmente.
