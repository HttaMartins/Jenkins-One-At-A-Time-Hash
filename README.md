# 🔑 Jenkins One At A Time Hash

Projeto de **Estrutura de Dados** implementando o algoritmo de hash **Jenkins One At A Time** em linguagem C.

---

## 🛠️ Compilando o Programa

Para compilar o programa, certifique-se de que os arquivos abaixo estejam na **mesma pasta**:

- `main.c`  
- `jenkins.c`  
- `jenkins.h`  

### 💻 Comando de compilação:

```bash
gcc main.c jenkins.c -o programajenkins
```
#### 🚀 Executando o programa:

```
./programajenkins
```

Após isso, o programa estará funcionando normalmente!
